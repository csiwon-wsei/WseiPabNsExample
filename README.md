# Programowanie aplikacji backendowych
Repozytorium zawiera przykładowy projekt tworzony w trakcie zajęć konwersatoryjnych

## Wykład 1

Omówienie Clean Architecture i modularnego monolitu.

## Wykład 2
Stworzenie rozwiązania typu modularny monolit. 
Przykład bardzo prostej aplikacji prezentującej użytkownikom filmy. Do filmu użytkownik może dodać receznję z oceną.

Zdefiniowane moduły w trakcie zajęć:
* ApplicationCore
* Infrastructure
* UnitTests
* WebApi
